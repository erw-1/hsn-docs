# Your portable.md site

Generated with [portable.md Editor](https://editor.portable.md/). More information: [portable.md](https://portable.md/).

This repository publishes a static website generated by the editor: no build step and no server software.

## What is in the repository root

- `index.html`, `pmd-reader-dist/` and any `pmd-custom-*.css`: the generated site and the reader that displays it. Do not edit them; every export rebuilds them.
- `content/`: your project (Markdown, `pmd.json`, images and other files). Open this repository's project in the editor to keep working: saving it updates the site.
- `.pmd-publish.json` and `.nojekyll`: bookkeeping for the editor and for GitHub Pages. Keep them.

## Turn on GitHub Pages

1. In the repository, open **Settings > Pages**. Under **Build and deployment**, choose **Deploy from a branch**, pick your branch and `/ (root)`, then save.
2. After a minute or two the site is live at `https://<your-name>.github.io/<repository>/`.
3. In the editor, open **Project config**, set **Site URL (canonical)** to that address and publish again, so links, the sitemap and sharing previews use it.

## Publishing again

Publish from the editor again to update the site. It replaces only the files it created (they are listed in `.pmd-publish.json`) and leaves everything else alone.

The editor wrote this file once, when it first published here. You can edit or delete it: it will not be touched or created again.
